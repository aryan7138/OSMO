🔗 **Live Demo:** [https://aryan7138.github.io/OSMO/grix.html](https://aryan7138.github.io/OSMO/grix.html)

---

## ✨ Key Features

*   **Immersive Preloader:** A custom loading screen that waits for actual image decoding and font loading before revealing the page, complete with a progress percentage.
*   **Editorial Design System:** A sophisticated mix of Playfair Display, Inter, and Space Grotesk typography, utilizing a bone/ink color palette with an accent orange.
*   **Responsive Layout:** Fluid typography and CSS Grid/Flexbox ensuring the experience works beautifully on mobile, tablet, and desktop.
*   **Smooth Overlays:** Interactive full-screen sections (Explore, About, Contact) that open with a sleek "curtain wipe" animation.
*   **History API Integration:** Seamless navigation where the back button correctly closes overlays and returns users to the main page.
*   **Scroll Reveal Animations:** Sections fade in elegantly as the user scrolls, powered by `IntersectionObserver`.
*   **Interactive FAQ:** Accessible accordion-style FAQ section with smooth expand/collapse transitions.
*   **Copy to Clipboard:** A built-in utility to quickly copy the brand's email address.
*   **Custom Marquee & Stats:** Infinite scrolling text ticker and animated statistic counters.

## 🛠️ Technologies Used

*   **HTML5** (Semantic structure, SEO meta tags)
*   **CSS3** (Custom Properties, CSS Grid, Flexbox, Animations, Clip-path transitions)
*   **Vanilla JavaScript** (No frameworks or libraries, pure DOM manipulation)
*   **Font Awesome 6** (Icons)
*   **Google Fonts** (Playfair Display, Inter, Space Grotesk)
